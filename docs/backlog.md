## 📌 합의 사항 — 쿠폰·포인트를 결제에 어떻게 붙일지

결제는 **"서버가 저장한 주문 금액 = 토스 승인 금액"** 으로 검증합니다(금액 위변조 방지). 그래서 할인은 **주문 생성 시점**에 적용합니다.

```
1. 주문 생성 API에 couponId, usePoints 추가
2. 서버가 검증·계산 → 할인 반영된 최종 금액을 주문 totalPrice로 저장
3. 결제는 그 금액으로 승인  → 결제 파트 수정 없음
4. 주문 취소·결제 실패 시 쿠폰·포인트 복구 필요 (재고 예약→해제와 같은 패턴)
```

아직 안 정한 것:
- **포인트로 전액 결제(0원)** → 토스 승인이 불가능. 별도 처리 or "최소 결제 금액" 제약 필요
- **환불 시 쿠폰 복구 정책** → 되살릴지 소멸시킬지

## 실행 방법

```bash
docker compose up -d      # MySQL + Redis (soldout DB 자동 생성)
./gradlew bootRun         # 백엔드 (또는 IntelliJ 실행)

cd frontend-v2 && npm install && npm run dev    # http://localhost:5173
```

**환경 변수**
- 루트 `.env` — `MYSQL_*`, `KAKAO_*`, `JWT_SECRET`, `TOSS_SECRET_KEY`, `MAIL_USERNAME`, `MAIL_PASSWORD`
- `frontend-v2/.env` — `VITE_TOSS_CLIENT_KEY` (백엔드 시크릿 키와 **같은 상점** 키)

**알아두면 좋은 것**
- DB를 완전히 초기화하려면 `docker compose down -v` 후 다시 `up -d`
- 관리자 기능은 DB에서 `role='ADMIN'`으로 바꾼 뒤 **재로그인** 필요
- 토스 테스트 환경엔 전용 테스트 카드가 없습니다. 본인 카드로 결제해도 **실제 출금되지 않습니다**
- 프론트가 두 개입니다: `frontend`(기존), `frontend-v2`(신규). 포트가 같아 동시 실행은 안 됩니다
